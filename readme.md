# llm-wiki
基于 Karpathy `llm.wiki` 理念，结合 Obsidian + Claude 实现的增量式知识库模板。

## 项目简介
这是一个轻量化、可直接上手的增量式知识库项目。
核心目标是：**只增不改、自动关联、永久沉淀**，告别碎片化笔记。

- 基于 Obsidian + Karpathy llm.wiki 理念构建
- 使用 Claude（Clandian 插件）自动生成笔记关联与延伸内容
- 纯本地存储，无数据泄露风险
- 支持双向链接与图谱视图，轻松搭建个人知识网络

## 快速上手
1.  **安装 Obsidian**
    - 官网下载并安装 Obsidian，创建一个新仓库。
2.  **克隆/复制本仓库**
    ```bash
    git clone https://github.com/你的用户名/llm-wiki.git
    ```
    将仓库内所有文件复制到你的 Obsidian 仓库目录。
3.  **安装 Clandian 插件**
    - 打开 Obsidian → 设置 → 第三方插件，关闭安全模式。
    - 搜索 `Clandian` 并安装，配置你的 Claude API Key。
4.  **使用增量笔记模板**
    - 新建笔记，命名格式：`YYYYMMDD-笔记标题.md`
    - 参考 `CLAUDE.md` 中的 Prompt，调用 Claude 自动生成关联与总结内容。

## 核心优势
- **只增不改**：历史笔记永久保留，不删除、不篡改，完整沉淀学习轨迹。
- **AI 自动关联**：新增笔记时，Claude 自动匹配旧笔记，生成双向链接。
- **低成本维护**：无需手动整理分类，大幅降低知识沉淀的维护成本。
- **知识可视化**：通过 Obsidian 图谱视图，直观查看知识网络。
